This is where I'll write about what I'm working on — mostly generative models,
flow matching, and whatever my thesis turns up along the way.

## How to write a new post

Add a markdown file to `_posts/` named `YYYY-MM-DD-some-slug.md`, with front
matter at the top:

```markdown
---
title: "Your title here"
date: 2026-08-10
description: "One line, shown on the blog index."
tags: [flow-matching, diffusion]
---

Your content, in normal markdown.
```

Commit and push it. GitHub Pages rebuilds the site automatically, usually within
a minute. The `description` and `tags` fields are both optional.

Code blocks, images (put them in `assets/`), tables, and LaTeX-free math all
work out of the box.
