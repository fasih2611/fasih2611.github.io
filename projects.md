### [mean-flow](https://github.com/fasih2611/mean-flow)
Mean-flow generative models: training and evaluation code used for my thesis on
one-step sampling and sample diversity.

### [DDPM_torch](https://github.com/fasih2611/DDPM_torch)
A PyTorch implementation of denoising diffusion probabilistic models, written
from the paper.

### [GRPO-PPO-RPO](https://github.com/fasih2611/GRPO-PPO-RPO)
Implementations of GRPO, PPO, and RPO for language model alignment, applied to
SmolLM2.

### [stable-diffusion](https://github.com/fasih2611/stable-diffusion)
Latent text-to-image diffusion, explored end to end.

### [RoadDamageDetection](https://github.com/fasih2611/RoadDamageDetection)
A road quality quantification system built on segmentation models.

### [DLT3d](https://github.com/fasih2611/DLT3d)
A Python implementation of the Direct Linear Transform, mapping 3D world
coordinates to 2D image coordinates and back.

### [LLMfastapi](https://github.com/fasih2611/LLMfastapi)
A spreadsheet-analysis API built on FastAPI and the Anthropic API.
